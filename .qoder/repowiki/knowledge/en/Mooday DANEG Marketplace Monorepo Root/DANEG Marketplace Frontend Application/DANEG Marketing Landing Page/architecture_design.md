Single-page React component tree rooted at `Landing.tsx`, which is a Next.js server component that prerenders all static sections and only delegates interactive parts to client components. Language selection is driven by a `?lang=en|ar` query parameter resolved in `copy.ts`, which exports a typed `Lang` union and a full `COPY` record of EN/AR strings consumed throughout the page. Direction (`dir=rtl` for Arabic) is set on the root `<div>` and synced to `<html>` via `DocumentDirSync.tsx` after hydration so SEO tags and `::dir()` selectors stay consistent. Interactive sub-components — `LangToggle` (URL-based language switch), `Reveal` (IntersectionObserver scroll-in animation respecting `prefers-reduced-motion`), and `LandingInstallPrompt` (bilingual PWA install dialog sharing a 7-day localStorage cooldown with the app shell) — are marked `'use client'`. All visual styling is isolated in `landing.module.css` under a `.landing` namespace using CSS custom properties for the champagne/plum/cream palette, with RTL variants handled via `[dir="rtl"]` selectors and inline `scaleX(-1)` transforms on arrow icons. The page composes its sections (hero, pulse stats, piece marquee, value props, category mosaic, lifestyle split, how-it-steps, editorial quote, trust grid, closing CTA, footer) as sequential `<section>` elements, each data-driven from `COPY[lang]`.
