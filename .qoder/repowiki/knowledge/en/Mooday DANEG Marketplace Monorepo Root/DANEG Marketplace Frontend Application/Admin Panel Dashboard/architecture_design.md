The module is a flat collection of React client components under `src/components/admin/` that compose the `/app/admin` page. `AdminTypes.ts` defines the shared `AdminTab` union type used by every tab and the sidebar to enforce consistent navigation keys. `AdminSidebar.tsx` renders the left nav with badge counts (pending listings, open disputes, open reports) and an RTL-aware layout; `AdminTopbar.tsx` shows the live/demo/not-connected status and language toggle. Each domain area is a single tab component (`AdminOverviewTab`, `AdminListingsTab`, `AdminOrdersTab`, `AdminUsersTab`, `AdminDisputesTab`, `AdminReportsTab`, `AdminBroadcastTab`, `AdminAuditLogTab`) that receives data via props and exposes action callbacks (e.g. `onApprove`, `onReject`, `onFeature`, `onSuspendUser`). Tabs are pure presentational/stateful UIs — they do not call Supabase directly but instead invoke server actions imported from `@/services/admin/actions`, whose types (`AdminDashboardStats`, `AdminListingSummary`, `AdminAuditLogEntry`, etc.) are re-imported here. The test file `AdminPanel.test.tsx` mocks all server actions to exercise the demo/mock mode path and verifies tab switching, language toggling, and stat card rendering.
