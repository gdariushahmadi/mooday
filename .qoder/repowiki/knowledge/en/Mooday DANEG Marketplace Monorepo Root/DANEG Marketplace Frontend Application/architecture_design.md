The module is split by Next.js App Router conventions: `src/app/` declares file-system routes (marketing landing, authenticated shell, admin dashboard, auth callback, preview embed) that import view components from `src/components/`; `src/components/` holds reusable view modules grouped by feature (admin panel, landing page, listing form, plus dozens of marketplace views like chats, orders, disputes, settings). Cross-cutting state and routing are centralized in `src/context/AppContext.tsx` (global app state, chat read tracking) and `src/hooks/useAppNavigation.ts` (programmatic navigation), which all view components consume. `src/types/navigation.ts` defines shared route shape types used by both the navigation hook and views. Server-side API endpoints live under `src/app/api/` (health, Stripe webhook) alongside the client routes, while `src/app/layout.tsx` and `globals.css` provide the root layout and styling consumed by every child route.
