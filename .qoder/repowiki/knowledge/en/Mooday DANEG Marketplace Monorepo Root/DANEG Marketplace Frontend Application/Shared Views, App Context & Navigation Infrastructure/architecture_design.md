Three cooperating layers form the app shell:
- `src/context/AppContext.tsx` is the single source of truth for all domain data (listings, cart, orders, chats, notifications, user profile, auth, addresses, payment methods, reports, disputes). It exposes one `AppProvider` wrapping a `createContext<AppContextType>` and uses `useLocalStorageState` plus `useSyncExternalStore` to persist state to localStorage keys defined in `STORAGE_KEYS`. A `phase2Backend` handle from `@/services/backend` lets each store switch between local mock mode and Supabase-backed remote mode at runtime, with `marketplaceMode` gating which backend is active.
- `src/hooks/useAppNavigation.ts` centralises navigation state (`currentView`, `activeTab`, overlay ids like `selectedProduct`, `activeChatThreadId`, `activeSellerId`, `activeCategory`, `activeOrderId`, `activeListingId`) and exposes grouped hook families (`useProductNav`, `useAuthNav`, `useOrderNav`, `useProfileNav`, `useChatNav`, `useSellerNav`) plus the composite `useAppNavigation()`. Deep-linking is driven by URL query params via `readUrlParam` and mirrored back into the URL through `history.replaceState`; tab↔view mapping lives in `src/types/navigation.ts` (`TabId`, `ViewState`, `VALID_VIEWS`).
- `src/components/AppContent.tsx` is the view router: it consumes `nav` from `useAppNavigation` and renders exactly one view component per `currentView` value, also handling two overlay views (`ProductDetailsView`, `ChatOverlay`) that take precedence over the main switch. All other leaf view components live alongside it under `src/components/` and are pure presentational/stateless consumers of `useApp()` and `useAppNavigation()`.
- The `src/components/admin/` sub-package is a self-contained admin dashboard built on the same context, with `AdminSidebar`/`AdminTopbar` chrome and one tab component per admin feature (Listings, Orders, Users, Disputes, Reports, Audit Log, Broadcast).
Dependency direction: views → `useAppNavigation` → `AppContext` → `@/services/backend` mappers; types flow outward only via `src/types/navigation.ts`.
