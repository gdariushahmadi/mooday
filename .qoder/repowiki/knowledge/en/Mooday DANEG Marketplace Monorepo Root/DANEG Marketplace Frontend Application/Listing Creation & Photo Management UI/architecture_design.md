The module is a flat collection of three React 'use client' components under `src/components/listing/` with no internal sub-packages. `ListingForm.tsx` is the central orchestrator: it owns all form state (titles, descriptions, category, condition, price, size, color, authenticity flag, photos), persists draft state to `localStorage` via a configurable `draftKey`, performs permissive Phase-1 validation (requires EN title + price), and composes child components. It delegates image staging to `ListingPhotoPicker.tsx`, which validates MIME against `@/services/backend` allow-lists, enforces a 10 MiB cap, resizes oversized images on a canvas to a 1600px long edge, and emits `blob:` URLs; it also exposes an `onFileStage` callback so the parent can map each staged `File` to its URL for later upload via `media.upload`. `BrandAutocomplete.tsx` is a lightweight native `<datalist>` combobox over `PREMIUM_BRANDS` from `@/data/premium-brands` that auto-fills the Arabic brand name via `brandArFor`. All user-facing strings are localized through `isAr`-gated copies (`LISTING_FORM_COPY_EN` / `_AR`, `PhotoPickerCopy`) rather than a translation library. Dependencies flow one-way: this module imports shared data (`@/data/categories`, `@/data/attributes`, `@/data/mock-images`, `@/data/premium-brands`), formatting (`@/lib/format`), and backend constants (`@/services/backend`); it never imports application context directly except for the `Product` type shape, keeping the form stateless beyond local React state.
