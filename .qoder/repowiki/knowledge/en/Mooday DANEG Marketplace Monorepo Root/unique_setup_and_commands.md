`npm run dev` starts the Next.js dev server; `npm run build` produces a `.next/standalone` bundle runnable via `npm run start:standalone`. Local Supabase is bootstrapped with `npm run supabase:start` and torn down with `supabase:stop`. The full verification pipeline runs `npm run verify` (typecheck → lint → unit tests → build), while Phase 2 integration runs `npm run test:phase2` which chains DB tests, auth smoke, U3-U8 smoke, and Playwright E2E.
