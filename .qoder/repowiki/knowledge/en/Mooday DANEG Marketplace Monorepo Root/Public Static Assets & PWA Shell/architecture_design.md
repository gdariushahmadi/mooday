Flat asset tree rooted at `public/` consumed directly by the Next.js server. Subdirectories group content by purpose: `brand/daneg/` holds multi-format (SVG/PNG/PDF) horizontal, vertical, and mark variants of the DANEG logo; `icons/` provides favicon, maskable, and Apple touch icons referenced from `manifest.json`; `landing/`, `products/`, and `sellers/` hold marketing, catalog, and profile images; `showcase/` contains UI screenshots plus an `index.html` gallery. Root-level files configure the PWA (`manifest.json` with shortcuts, protocol handlers, and edge-side-panel settings), register the service worker (`sw.js`) which implements versioned cache buckets (`daneg-v1-static`, `-runtime`, `-images`) with distinct strategies per request type (network-first navigations falling back to `/offline.html`, cache-first static assets, stale-while-revalidate images, and sensitive API/auth requests bypassed entirely), and provide SEO/offline support via `robots.txt`, `offline.html`, and `favicon.ico`. Dependency direction is one-way: the runtime references these paths but nothing in this module imports application code.
