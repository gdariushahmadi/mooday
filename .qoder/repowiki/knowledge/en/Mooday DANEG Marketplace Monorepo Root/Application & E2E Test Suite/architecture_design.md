Two parallel test suites coexist under `tests/`: a Vitest suite (`copyGuard.test.ts`) that scans `src/**/*.ts` files at runtime to forbid banned English and Arabic phrases from the DANEG rebrand, using shared constants and exemption logic from `src/lib/banned-phrases`; and a Playwright suite under `tests/e2e/` that drives the live app through browser automation. The e2e layer is split by feature: `daneg-rebrand.spec.ts` asserts landing page wordmarks, trust badges, brand chip filtering, sell form fields, and absence of banned copy in both English and Arabic locales; `phase2-auth.spec.ts` orchestrates full sign-up flows by polling a local Mailpit instance (configured via `SUPABASE_LOCAL_MAILPIT_URL`) to extract six-digit OTPs from confirmation emails and complete verification. Tests depend on the application source tree for content scanning but are otherwise isolated from the build pipeline.
