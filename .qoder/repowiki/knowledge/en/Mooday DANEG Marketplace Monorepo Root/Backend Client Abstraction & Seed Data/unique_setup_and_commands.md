Running against Supabase requires setting `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (or `NEXT_PUBLIC_SUPABASE_ANON_KEY`), and `NEXT_PUBLIC_SITE_URL`; enabling marketplace features additionally sets `NEXT_PUBLIC_MARKETPLACE_DATA_SOURCE=supabase`. Admin Server Actions require `SUPABASE_SERVICE_ROLE_KEY` set on the Node process — this key must never be prefixed with `NEXT_PUBLIC_` because it would leak into the browser bundle.
