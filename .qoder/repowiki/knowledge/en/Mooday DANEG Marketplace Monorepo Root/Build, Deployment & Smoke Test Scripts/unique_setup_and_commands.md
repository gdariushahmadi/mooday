`bash scripts/build-standalone.sh` builds the Next.js app with production env vars and stages a tarball in `.deploy/`; add `--upload` to SCP it to the cPanel host using `MOODAY_SSH_KEY`/`MOODAY_SSH_HOST`/`MOODAY_SSH_PORT`/`MOODAY_REMOTE_DIR`. Run smoke tests via `npm run test:phase2:*` (e.g. `test:phase2:smoke`, `test:phase2:e2e`) which start the local Supabase stack via `supabase:start` when needed. Seeding requires `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, and `MOODAY_DEMO_SEED_CONFIRM=YES`.
